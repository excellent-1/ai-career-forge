# AI Career Forge DFW — project proposal

I propose building AI Career Forge DFW, an original, GitHub-based platform that combines an interactive AI engineering e-book, hands-on coding labs, portfolio development, and evidence-based job matching. Learners progress through multiple-choice questions, fill-in-the-code exercises, debugging challenges, and practical labs covering Python, TypeScript, FastAPI, LangChain, LangGraph, retrieval-augmented generation, MCP, context engineering, and agent evaluation. Every chapter produces a deployable AI application with tests, documentation, and a public demonstration. As learners demonstrate skills, the planned platform will connect their work to recently posted Dallas–Fort Worth and McKinney-area AI engineering positions, showing evidence and remaining gaps.

I will develop the platform using an AI coding assistant across architecture, implementation, testing, debugging, and deployment, while documenting which assistant responses I prefer and why. The project provides substantial engineering challenges: secure assessment, stateful workflows, retrieval, evaluation reliability, posting freshness, and explainable matching. The Chapter 1 working draft supplies a practical starting point: a typed requirements analyzer, interactive lessons, a free baseline, optional model integration, evidence checks, and repeatable tests. Subsequent milestones expand it into an independently owned product with measurable behavior and a development journal recording the effects of AI-assisted engineering.
